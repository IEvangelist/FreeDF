### What's new

- A concise, consumer-focused NuGet README with install commands, text extraction,
  PNG rendering, and bundled-font examples replaces the editor-focused README.
- NuGet links now use absolute URLs: no broken relative screenshot or documentation
  paths. Package metadata includes the FreeDF homepage, source repository,
  version-specific release notes, and MIT license.
- Successful publication now creates a GitHub Release with generated change notes,
  installation instructions, and all six packages plus symbol packages attached.
- Release checks inspect every packed README and its licensing metadata, and run
  the documented rendering examples in an installed-package consumer.

### Compatibility

This release changes package documentation, metadata, and release automation;
it does not change library APIs or rendering behavior from preview.3.
All six packages target .NET 10 and use version `0.1.0-preview.4`.
Use preview.3 or later; preview.2 has a fallback-font packaging defect.
Preview APIs and output may change in future versions. Full PDF 2.0 parity
is not claimed; validate your own PDF corpus before upgrading.
